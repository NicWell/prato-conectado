# Cadastro de doador no React

Pela tela de cadastro, selecione doador empresa ou pessoa física e preencha os dados. O React envia o formulário para `POST /api/auth/cadastro`. Um cadastro concluído passa para `PENDENTE` e pode ser consultado no painel administrativo.

Para configurar a API e testar cadastro, aprovação e login, veja [integração do frontend](INTEGRACAO_AUTH_FRONTEND.md).
